🔔 Discord Webhook 설정 방법

1단계 — Discord에서 웹후크 URL 발급

  1. 알림받을 Discord 서버 채널 우클릭 → 채널 편집
  2. 좌측 연동 → 웹후크 → 새 웹후크
  3. 웹후크 URL 복사 클릭
📌 URL 형식: https://discord.com/api/webhooks/숫자/문자열

2단계 — 채널 화면에서 설정

  1. 복사한 URL을 Webhook URL 칸에 붙여넣기
  2. 전송 주기 선택 (30분 / 1h / 2h / 4h)
  3. 저장 → OFF 클릭으로 ON 전환
