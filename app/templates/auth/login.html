🚀 시작 순서

  1. 회원가입 후 7일 이내 승인 요청 제출
  2. 관리자가 채널 배정 및 만료일 설정 후 승인
  3. 마이페이지에서 거래소 API 키 등록 (AES-256 암호화 저장)
  4. 배정된 채널 입장 → 그리드 설정 후 시작

🔑 거래소 API 키 발급

빗썸 — 마이페이지 → API 관리 → API 생성

  • 권한: 조회 + 주문 만 선택
  • 출금 권한 절대 체크 금지
  • 서버 IP를 허용 IP로 등록 권장

한국투자증권 — KIS Developers → 앱 등록 → App Key/Secret 발급

📊 그리드 설정 가이드

투자 가능 금액의 50%를 코인으로 먼저 매수 후 그리드 시작. 나머지 50%는 현금으로 유지.
  • 기준 위치: 현재 매수 평균 단가 입력 (또는 자동입력 버튼)
  • 기준 단위: 격자 간격 — 기준가의 0.6% 권장
  • 초기 보유량 H₀: 현재 보유 코인 수량
  • 격자 칸수: 매수/매도 각 방향 주문 수 (4~6 권장)
  • 추세 추종: 강(상승장) / 중(기본) / 약(횡보·하락)

🔔 Discord 알림 설정

채널 채널 화면 하단의 Discord 알림 설정 패널에서 Webhook URL을 입력합니다.

Webhook URL 발급 방법: Discord 서버 → 채널 설정 → 연동 → 웹후크 → 새 웹후크 → URL 복사

⚠️ 투자 주의사항

투자는 본인의 판단과 책임 하에 진행하세요. 과거 수익률이 미래를 보장하지 않습니다.

🔔 Discord Webhook 설정 방법

1단계 — Discord 서버에서 웹후크 생성

  1. 알림을 받을 Discord 서버에 접속
  2. 알림받을 채널 우클릭 → 채널 편집
  3. 좌측 메뉴에서 연동 클릭
  4. 웹후크 → 새 웹후크 클릭
  5. 이름 설정 후 웹후크 URL 복사 클릭
📌 URL 형식: https://discord.com/api/webhooks/숫자/문자열

2단계 — JaeTech247 채널에 입력

  1. 채널 화면 하단 🔔 Discord 알림 설정 패널 확인
  2. Webhook URL 칸에 복사한 URL 붙여넣기
  3. 전송 주기 선택 (30분 / 1시간 / 2시간 / 4시간)
  4. 저장 버튼 클릭
  5. OFF 버튼 클릭 → ON 으로 전환
